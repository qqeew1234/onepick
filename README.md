# 🎯 ONE-PICK (원픽)

> 선택의 피로를 완전히 제거하는 **결정 지정형(Prescriptive) 커머스 플랫폼**

---

## 📌 1차 구현 상세 (Phase 1 Implementation)

[requirement](file:///C:/Users/qqeew/Projects/onepick/requirement) 명세서에 정의된 핵심 원칙과 아키텍처를 바탕으로 1차 엔진 및 백엔드/웹 서비스 구현이 완료되었습니다.

### 1. 실시간 결정형 검색 레이어 (Deterministic Search Engine)
* **초저지연(Sub-10ms) 응답 보장**: 인메모리 사전 매핑 및 Inverted Index 기반 검색으로 평균 **1~2ms대** 즉각 응답.
* **한국어 형태소 분석기 (Nori Analyzer)**: Lucene Nori 기반으로 질의어에서 명사와 복합어(자취, 가성비, 무선청소기, 노캔 등)를 분해하고 불용어 필터링.
* **형태소-태그 매핑 사전 (TagDictionary)**: 동의어/속성 태그(자취/원룸, 가성비, 하이엔드 등) 정규화.
* **단 하나의 정답 (Hero Item) 및 1줄 선정 사유**: 
  * "이 중에서 골라봐"가 아닌, 소비자가 고민할 필요 없는 단 1개의 Hero Pick 지정.
  * 질의 의도와 상품 강점에 맞춘 명확한 **1줄 당위성 문구** 동적 제공.
* **선택 피로 방지 대안 (Alternatives)**:
  * 비교 피로를 유발하지 않도록 가성비/하이엔드 대안을 **최대 2개**로 엄격히 제한 (총 결과 1~3개 한정).

### 2. 제로 톨러런스 바이럴 방지 엔진 (Zero-Tolerance Anti-Viral Engine)
* **텍스트 패턴 분석**: "협찬", "원고료", "지원받아 작성", 위장형 "내돈내산" 문구 및 봇 어뷰징 탐지.
* **시계열 이상 탐지**: 단기간 내 리뷰/언급량이 기준치 대비 3.5배 이상 비정상 폭증한 상품 감점 및 격리.
* **교차 검증 (Cross-Validation)**: 상업성 블로그 발행량 대비 순수 커뮤니티(디시, 클리앙, 에펨코리아 등) 실구매자 정서 분석 결합.
* **완전 격리**: 바이럴 스코어가 0.0을 초과하거나 격리 대상 상품은 검색 결과에서 100% 원천 배제.

### 3. 비동기 데이터 파이프라인 (Async Pipeline & Logging)
* 사용자 검색 요청을 Kotlin Coroutine 채널을 통해 비동기 수집 (검색 레이턴시 0ms 영향).
* 고빈도/인기 검색어 실시간 통계 및 레이턴시 모니터링.

### 4. Zero Choice Fatigue 웹 인터페이스
* `http://localhost:8080` 접속 시 즉시 확인 가능한 미니멀 UI 제공.
* 실시간 연산 시간 배지 (`⚡ 엔진 연산: Sub-10ms`).
* 원픽 정답 카드 + 1줄 선정 사유 하이라이트 + 최저가 제휴(Affiliate) 링크.
* 대안 비교 접이식 아코디언 및 바이럴 탐지 시뮬레이터 탑재.
